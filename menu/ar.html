Kamera Butuh HTTPS

Browser memblokir akses kamera di koneksi HTTP. AR berbasis kamera hanya bekerja di HTTPS atau localhost.

💡 Cara fix — jalankan dengan HTTPS:

# Install sertifikat lokal (sekali saja) npx mkcert -install npx mkcert 192.168.56.1 # Jalankan server dengan HTTPS npx http-server -S -C 192.168.56.1+1.pem -K 192.168.56.1+1-key.pem -p 8080

Atau akses dari komputer yang sama via http://localhost:8080
